# Задание 3. Класс комплексных чисел

## Условие

Составить описание класса для представления комплексных чисел. Обеспечить выполнение операций сложения, вычитания и умножения комплексных чисел.

## Как запустить

```
python complex.py
```

## Объяснение кода

Комплексное число вида a + bi задается двумя числами, поэтому в классе `Complex` всего два поля: `re` (действительная часть) и `im` (мнимая часть).

Операции написаны не обычными методами, а специальными: `__add__`, `__sub__` и `__mul__`. Это перегрузка операторов: когда Python видит `z1 + z2`, он сам вызывает у `z1` метод `__add__` и передает туда `z2`. Благодаря этому с объектами можно работать как с обычными числами.

Сложение и вычитание выполняются по частям: действительные части складываются с действительными, мнимые с мнимыми. Умножение раскрывается по формуле (a + bi)(c + di) = (ac - bd) + (ad + bc)i, потому что i² = -1. Именно эта формула записана в `__mul__`.

Каждая операция возвращает новый объект `Complex`, а исходные числа не меняются: после `z3 = z1 + z2` значения `z1` и `z2` остаются прежними.

Метод `__str__` выводит число в привычном виде a + bi. Если мнимая часть отрицательная, печатается минус, чтобы не было записи вида `11 + -2i`.

## Результат работы программы

```
4 + 2i
2 + 6i
11 - 2i
```
