# Задание 5. Класс для работы с паролями

## Условие

Реализовать класс для работы с паролями пользователей. Класс должен позволять генерировать безопасный пароль и осуществлять проверку пароля на безопасность. Безопасным будем считать такой пароль, который содержит не меньше 10 символов, среди которых обязательно должны быть строчные и прописные буквы латинского алфавита и цифры.

## Как запустить

```
python password.py
```

## Объяснение кода

В начале подключаются два стандартных модуля: `random` (из него берется функция `choice`, которая выбирает случайный элемент) и `string` (в нем лежат готовые наборы символов, все латинские буквы и все цифры).

В классе `Password` одно поле `value`, это сама строка пароля.

Метод `is_safe` проверяет пароль на безопасность. Он возвращает True, только если выполнены все четыре условия сразу:

- `len(self.value) >= 10`: длина не меньше 10 символов;
- `any(c.islower() for c in self.value)`: есть хотя бы одна строчная буква. Цикл перебирает символы строки, `islower` проверяет каждый, а `any` возвращает True, если хотя бы один подошел;
- то же самое с `isupper` для прописных букв;
- то же самое с `isdigit` для цифр.

Условия связаны через `and`, поэтому если не выполнено хотя бы одно, результат будет False.

Метод `generate` создает новый пароль. Параметр `n` это длина, по умолчанию 12. Алфавит собирается как `string.ascii_letters + string.digits` (все буквы и цифры). Затем `random.choice` n раз выбирает случайный символ, а `"".join(...)` склеивает их в строку.

Случайный набор символов может, например, не содержать ни одной цифры. Поэтому после генерации стоит цикл `while not self.is_safe()`: пока пароль не проходит проверку, он генерируется заново. Так метод гарантированно возвращает безопасный пароль.

В демонстрации проверяются два пароля (короткий "12345" и нормальный "MyPassword123") и генерируется новый. При каждом запуске сгенерированный пароль будет другим.
