# Задание 8. Класс Student и работа с JSON

## Условие

Разработать класс Student. Класс должен содержать поля для хранения данных: id, Фамилия, Имя, Отчество, Дата рождения, Адрес, Телефон, Факультет, Курс, Группа, Средний балл. Класс должен содержать конструкторы, методы для работы с полями класса и метод для вычисления величины стипендии в зависимости от среднего балла.

Создать массив объектов. Вывести:

a) список студентов заданного факультета;
b) списки студентов для каждого факультета и курса;
c) список студентов, родившихся после заданного года;
d) список учебной группы.

Предусмотреть возможность импорта и экспорта данных в файл в формате json.

## Как запустить

```
python students.py
```

## Объяснение кода

**Класс.** Конструктор `Student` принимает все одиннадцать полей из задания: `id`, `fam`, `name`, `otch`, `year` (год рождения), `addr`, `phone`, `fac`, `course`, `group`, `ball`. Год рождения хранится числом, так его проще сравнивать в пункте c и он без проблем записывается в JSON.

**Стипендия.** Метод `stipend` считает стипендию по среднему баллу:

| Средний балл | Стипендия |
|---|---|
| меньше 3 | 0 |
| от 3 до 4 | 2000 |
| от 4 до 4.8 | 3000 |
| 4.8 и выше | 4000 |

Проверки идут сверху вниз, и `return` сразу завершает метод. Поэтому, например, в проверке `ball >= 4` не нужно писать верхнюю границу 4.8: если бы балл был больше, сработало бы предыдущее условие.

**Вывод.** `__str__` задает, как студент выглядит при печати. Внутри строки вызывается `stipend()`, так что стипендия считается в момент печати.

**Массив объектов.** Создается список `students` из четырех студентов. Данные подобраны так, чтобы проверить все выборки: два факультета, разные курсы и группы, один студент с баллом ниже 3.

**Выборки:**

- a) перебираем всех студентов и печатаем тех, у кого `fac == "ИТ"`;
- b) `set` собирает факультеты без повторов, `sorted` упорядочивает их, внутри так же собираются курсы этого факультета. Тройной цикл печатает фамилии для каждой пары факультет и курс;
- c) печатаем тех, у кого `year > 2004`;
- d) печатаем тех, у кого `group == "Д-Э 18-24"`.

**JSON.** Экспорт: у каждого объекта есть готовый словарь всех полей `s.__dict__`, список таких словарей записывается функцией `json.dump`. `ensure_ascii=False` оставляет русские буквы читаемыми, `indent=2` добавляет отступы. Импорт: `json.load` читает список словарей, а `Student(**d)` превращает каждый словарь обратно в объект (две звездочки распаковывают словарь в именованные аргументы). Это работает, потому что ключи словаря совпадают с параметрами конструктора. В конце печатается число загруженных записей и первый студент, чтобы убедиться, что данные сохранились правильно.

После запуска рядом с программой появляется файл `students.json`.
