# Задание 7. Иерархия товаров и группа товаров

## Условие

Магазин реализует доставку товаров. Составить описание иерархии классов, описывающей некоторые товары. Реализовать класс, позволяющий формировать группы товаров с возможностью вычисления стоимости всей группы.

## Как запустить

```
python shop.py
```

## Объяснение кода

`Product` это базовый класс товара. У любого товара есть название `name`, цена `price` и вес `weight` (от веса считается доставка). Метод `delivery` в базовом классе возвращает 0, а метод `total` считает полную стоимость: цена + доставка.

Наследники переопределяют только доставку, у каждого вида товара свой тариф:

| Класс | Товар | Доставка |
|---|---|---|
| `Book` | книги | 50 руб. за кг |
| `Tech` | техника | 100 руб. за кг |
| `Food` | продукты | бесплатно |

Своих конструкторов у наследников нет, поэтому срабатывает конструктор `Product`. Главный момент: метод `total` написан один раз в базовом классе, но вызов `self.delivery()` внутри него подставляет формулу того класса, к которому реально принадлежит объект. Для книги посчитается тариф книги, для техники тариф техники.

`Group` это группа товаров (корзина заказа). Она не наследуется от `Product`, потому что группа не является товаром, она товары в себе содержит. Внутри хранится список `items`, метод `add` добавляет в него товар, а метод `total` складывает полные стоимости всех товаров через `sum`. В группе нет ни одной проверки типа товара: каждый объект сам знает, как считать свою стоимость. Если появится новый вид товара, класс `Group` менять не придется.

Проверка расчета из демонстрации: книга 2500 + 1.2 * 50 = 2560, микроволновка 8990 + 12.5 * 100 = 10240, кофе 750 + 0 = 750, итого 13550.
