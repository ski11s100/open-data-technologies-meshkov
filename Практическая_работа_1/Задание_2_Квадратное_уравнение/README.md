# Задание 2. Класс "Квадратное уравнение"

## Условие

Разработать класс Квадратное уравнение. Класс должен содержать конструкторы, методы для работы с полями класса и метод для решения квадратного уравнения. Продемонстрировать работу с этим классом.

## Как запустить

```
python equation.py
```

## Объяснение кода

В классе `Equation` три поля: коэффициенты `a`, `b` и `c` уравнения ax² + bx + c = 0. Они задаются в конструкторе.

Весь расчет находится в методе `solve`. Сначала считается дискриминант по формуле D = b² - 4ac. Дальше три случая:

- D < 0: метод возвращает строку "корней нет";
- D = 0: возвращается один корень x = -b / (2a);
- D > 0: считаются два корня по формуле (-b ± √D) / (2a) и возвращаются вместе.

Квадратный корень берется функцией `sqrt` из модуля `math`, поэтому в начале файла стоит `import math`.

В демонстрации проверены все три случая: уравнение с двумя корнями, с одним корнем и без корней. Объект создается прямо внутри `print`, отдельная переменная тут не нужна.

## Результат работы программы
