# Задание 4. Класс "Вектор" в трехмерном пространстве

## Условие

Составить описание класса для объектов-векторов, задаваемых координатами концов в трехмерном пространстве. Обеспечить операции сложения и вычитания векторов с получением нового вектора (суммы или разности), вычисления скалярного произведения двух векторов, длины вектора, угла между векторами.

## Как запустить

```
python vector.py
```

## Объяснение кода

По условию вектор задается координатами концов, поэтому конструктор принимает шесть чисел: начало (x1, y1, z1) и конец (x2, y2, z2). Внутри объекта хранятся координаты самого вектора: из конца вычитается начало, x = x2 - x1, и так же для y и z. Дальше все формулы работают с этими тремя числами.

Сложение и вычитание сделаны через перегрузку операторов `__add__` и `__sub__` и выполняются покоординатно. Результат это новый вектор, который откладывается от начала координат, поэтому в конструктор передается начало (0, 0, 0).

Метод `dot` считает скалярное произведение по формуле x1*x2 + y1*y2 + z1*z2.

Длина вектора это корень из скалярного произведения вектора на самого себя, поэтому `length` просто вызывает `self.dot(self)` и берет корень. Формулу √(x² + y² + z²) заново писать не нужно.

Угол находится из формулы скалярного произведения: cos(угла) = (a, b) / (|a| * |b|). Функция `acos` возвращает угол в радианах, поэтому результат переводится в градусы функцией `math.degrees`.

В демонстрации созданы два вектора по точкам начала и конца и выведены все требуемые величины: сумма, разность, скалярное произведение, длина и угол.
