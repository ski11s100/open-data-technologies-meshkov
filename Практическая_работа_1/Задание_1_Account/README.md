# Задание 1. Класс Account (банковский счет)

## Условие

Реализовать класс Account, представляющий собой банковский счет. В классе должны быть пять полей: фамилия владельца, номер счета, процент начисления, дата открытия счета и сумма в рублях. Класс должен содержать конструкторы, методы для работы с полями класса и методы для выполнения следующих операций: смена владельца счета, снятие некоторой суммы денег со счета, пополнение счета, начисление процентов, конвертирование в доллары.

## Как запустить

```
python account.py
```

## Объяснение кода

Конструктор `__init__` создает объект и записывает в него пять полей из задания: `owner` (фамилия владельца), `number` (номер счета), `percent` (процент), `date` (дата открытия) и `amount` (сумма в рублях). У `amount` стоит значение по умолчанию 0, поэтому счет можно открыть и без денег.

Каждая операция из условия сделана отдельным методом:

- `change_owner` записывает новую фамилию в поле `owner`;
- `deposit` прибавляет сумму к счету;
- `withdraw` вычитает сумму, но сначала проверяет, хватает ли денег. Если не хватает, выводится сообщение, а сумма на счете не меняется;
- `add_percent` начисляет проценты по формуле: сумма + сумма * процент / 100;
- `to_dollars` делит сумму на курс. Курс задан параметром по умолчанию (90), при желании можно передать другой.

Метод `__str__` нужен, чтобы `print(a)` печатал понятную строку. Без него на экран вывелось бы что-то вроде `<__main__.Account object at 0x7f...>`.

В конце программы создается счет, и над ним по очереди выполняются все операции. После каждой печатается состояние счета, чтобы было видно, что изменилось.
