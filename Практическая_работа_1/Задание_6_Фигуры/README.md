# Задание 6. Система классов для плоских фигур

## Условие

Построить систему классов для описания плоских геометрических фигур: круг, квадрат, прямоугольник. Предусмотреть методы для создания объектов, перемещения на плоскости, изменения размеров и вычисления площади.

## Как запустить

```
python figures.py
```

## Объяснение кода

Сделана иерархия классов с наследованием:

```
Figure
├── Circle
└── Rectangle
    └── Square
```

`Figure` это базовый класс. В нем собрано то, что есть у любой фигуры: координаты `x`, `y` и метод `move(dx, dy)`, который сдвигает фигуру на dx по горизонтали и dy по вертикали. Метод `move` написан один раз и работает у всех фигур. Метод `area` в базовом классе возвращает 0, это заглушка, которую наследники переписывают своей формулой.

`Circle` (круг) наследуется от `Figure`. В конструкторе он вызывает `super().__init__(x, y)`, то есть поручает родителю записать координаты, а сам добавляет радиус `r`. Метод `resize(k)` умножает радиус на коэффициент k, `area` считает площадь по формуле π * r².

`Rectangle` (прямоугольник) тоже наследуется от `Figure`, хранит ширину `w` и высоту `h`. `resize(k)` умножает обе стороны на k, `area` возвращает w * h.

`Square` (квадрат) наследуется не от `Figure`, а от `Rectangle`, потому что квадрат это прямоугольник с равными сторонами. Его конструктор принимает одну сторону `a` и передает ее родителю дважды, как ширину и как высоту. Методы `area` и `resize` ему писать не нужно, они достаются от прямоугольника готовыми.

В демонстрации три разные фигуры лежат в одном списке. В цикле у каждой вызываются `move` и `resize(2)`, и Python сам выбирает нужный вариант метода по типу объекта. Это и называется полиморфизмом. `type(f).__name__` выводит имя класса, чтобы было видно, какая это фигура.
